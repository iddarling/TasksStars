# TaskStars - Telegram Bot

Система управления задачами и наградами для Telegram.

## Архитектура

- **handlers** - обработчики Telegram команд и callback'ов
- **services** - бизнес-логика
- **repositories** - работа с базой данных
- **models** - ORM модели SQLAlchemy
- **database** - инициализация и подключение к БД
- **keyboards** - inline клавиатуры
- **config** - конфигурация приложения

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd TaskStars
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate  # для Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

5. Отредактируйте `.env`:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
DATABASE_URL=sqlite+aiosqlite:///./bot.db  # или PostgreSQL
DAILY_REMINDER_TIME=09:00
```

6. Запустите бота:
```bash
cd bot
python main.py
```

## Команды бота

### Пользовательские команды:
- `/start` - запуск бота
- `/tasks` - список активных задач
- `/add_task` - создать новую задачу
- `/done` - отметить задачу выполненной
- `/rewards` - список доступных наград
- `/suggest_reward` - предложить новую награду
- `/balance` - проверить баланс баллов

### Административные команды:
- `/admin` - панель администратора
- `/pending_tasks` - задачи на утверждении
- `/pending_rewards` - награды на утверждении

## Бизнес-логика

### Задачи
- **Типы**: daily (ежедневные), one-time (разовые)
- **Статусы**: draft (черновик), active (активна), pending (на проверке), approved (подтверждена), rejected (отклонена)
- **Создание**: пользователи создают со статусом draft, администраторы сразу active
- **Выполнение**: пользователь отправляет доказательство, администратор подтверждает

### Награды
- **Типы**: системные (создает админ), предложенные пользователями
- **Статусы**: proposed (предложена), active (активна)
- **Получение**: пользователь обменивает баллы на награду

### Баллы
- Начисляются только после подтверждения выполнения задачи
- Списываются при получении награды
- Баланс рассчитывается динамически через историю операций

## Уведомления

Администратор получает уведомления о:
- Новых задачах на утверждении
- Выполненных задачах на проверке
- Предложенных наградах
- Запросах на награды

Пользователь получает уведомления о:
- Подтверждении задач
- Отклонении задач
- Подтверждении наград

## Напоминания

Используется APScheduler для:
- Ежедневных напоминаний (настраиваемое время)
- Напоминаний о невыполненных ежедневных задачах

## База данных

Поддерживаются:
- SQLite (для разработки)
- PostgreSQL (для продакшена)

Таблицы:
- `users` - пользователи
- `tasks` - задачи
- `task_completions` - выполнения задач
- `rewards` - награды
- `reward_requests` - запросы на награды
- `points_history` - история баллов
